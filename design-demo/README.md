# Launch Desk design demo

Open `index.html` in a browser to try the dashboard. The demo uses a recorded launch scenario. Approvals stay in the browser tab and can be undone in the activity log.

Edit `styles.css` for layout and colors, `app.js` for recommendations and interactions, `evidence.js` for the supplier email excerpts, and `art.js` for the countdown illustration. The demo runs independently of the main dashboard and requires no build or credentials.
